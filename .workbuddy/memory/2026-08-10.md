## 历史面板 v2（用户反馈迭代）

**用户反馈**：历史区纵向空间太小（仅 3 条）、`[ ]/[✓]` 文本勾选不适合产品、选中态仍有黑框。

**改动**：
1. **垂直空间**：删除 `_build_sidebar` 中"论文翻译查看器"副标题 QLabel；GroupBox 留白排查结论 = **三处叠加**：theme.py `QGroupBox margin-top 12px + padding-top 16px` + settings.py QFormLayout `top margin 14px`（合计 ~30px）→ 压缩为 margin-top 10px / padding-top 6px + form top 4px（合计 ~14px）
2. **真 Checkbox**：选择模式改 Qt 原生 checkbox（ItemIsUserCheckable）；自定义 `_CheckableList(QListWidget)` 重写 mousePressEvent——**可勾选 item 任意区域点击都手动 setCheckState 一次且不调 super**（Qt 的自动切换在 release 阶段 editorEvent，与其共存会双重翻转；全手动接管则无此问题）；QSS `::indicator` 主题化：unchecked 边框 text_secondary，checked 背景 accent + **check.svg 渲染的主题对比色对勾 PNG**（缓存 `%TEMP%/formtranspdf_theme/check_{dark,light}.png`，随主题切换）
3. **黑框修复**：选中态补 `QListWidget::item:selected:!active` 变体（**非激活窗口时 Qt 回退系统默认选中样式是黑框主因**）+ border/outline none

**关键坑（PySide6）**：
- `QListWidgetItem` **默认 flags 就含 ItemIsUserCheckable**——浏览模式必须显式 `flags &= ~ItemIsUserCheckable`，否则一直显示 checkbox
- `QListView.viewOptions()` 是 protected，PySide6 不可调用；`QStyleOptionViewItem.Feature` 在 PySide6 是 `ViewItemFeature`
- Qt checkbox 自动切换在 release 的 editorEvent，offscreen 下与自定义 press 拦截行为不可靠——全手动切换最稳

## 焦点框根除（黑框 v3）

**现象**：点击后聚焦时有黑框、转移焦点后消失 → 是**键盘焦点框（focus rect）**，`:selected:!active` 只解决窗口非激活场景。

**根治**：`self._list.setFocusPolicy(Qt.FocusPolicy.NoFocus)`（历史列表鼠标操作，无键盘导航需求；鼠标点击/选中/勾选不受影响）+ QSS 补 `:selected:focus` / `:item:focus` 变体双保险。

## 历史文件被占用无法删除（WinError 32）修复

**根因链**：
1. viewer 会话缓存 `_sessions[path]` 长期持有 QPdfDocument；QPdfView 渲染的 PDF 被"看过"后文件句柄不释放
2. **PySide6 下 QPdfDocument 的 close()/deleteLater()/GC 均不释放 Windows 文件句柄**（实测三种都 LOCKED），只有 `shiboken6.delete(doc)` 立即析构 C++ 对象才能归还句柄
3. MainWindow 的 viewer 可能是 `DualRoughViewer`（rough_layout=dual），它转发对齐 API 但缺新方法 → AttributeError 被吞

**修复**：
- `PDFViewer.release_sessions(paths)`：按路径从 `_sessions` 弹出文档；若为当前显示文档先 `setDocument(None)` + `layout_engine.set_document(None)` 清引用；然后 `shiboken6.delete(doc)` 立即释放句柄
- `DualRoughViewer.release_sessions`：转发左右两栏
- `HistoryPanel` 新增 `about_to_delete_files = Signal(list)`，`_confirm_and_delete` 确认后、unlink 前发出
- `MainWindow._on_history_delete_files`：释放 viewer 句柄 + 关闭引用被删文件的标签页（从后往前 `_close_doc_tab`）

**测试要点**：fitz 生成真实 PDF → QPdfDocument 加载后 unlink 必现 WinError 32 → shiboken6.delete 后可删；全链路（打开历史→删除）单栏/双栏均通过。测试脚本曾误用独立 panel（信号未连 MainWindow）导致误判失败——信号链必须真实连接。
