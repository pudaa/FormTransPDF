# FormTransPDF v1.1.0 更新说明

**功能：全新「粗糙翻译」快速通读引擎、多文档标签页与无边框窗口；大文档性能大幅优化，数百页论文加载全程可交互**

自 v1.0.2 以来的三周开发，围绕三条主线：**更快地读**（粗糙翻译）、**更舒服地管理**（标签页 + 无边框窗口）、**更大胆地打开**（大文档性能）。

---

## ✨ 新功能

### 粗糙翻译（本版本核心）

全新的轻量翻译路线：不重排版、不生成新 PDF，直接在原文文本层之上叠加译文白底覆盖层。

- **按页流式呈现**：点击即译，译文逐段浮现，未译段保持原文，无需等待全文完成
- **双栏对照 / 单栏覆盖**两种布局，与 BabelDOC 精确翻译共用同一「输出模式」配置
- **学术向翻译提示词**：保留公式、变量、引用标记（[12]、(Smith, 2020)、Fig. 3）原样不译
- **批量合并请求 + 全局并发调度**：翻译请求数降低为逐段方式的 1/N，长文明显提速
- **失败自动重试**（指数退避），结束后给出成功/失败统计，再次点击只补译失败段
- **译文持久化缓存**：按源文件内容指纹落盘，重新打开同一论文免翻译直接呈现
- **历史面板新增「粗译」记录**：点击重新打开源文件，自动命中缓存
- **进度条实时显示**；运行中可随时停止，已完成段落保留可续译
- 智能过滤纯数字/公式碎片/参考文献/页眉页脚，不浪费 API 也不污染阅读
- Alt+拖拽可将遮挡的字块拖出查看，双击复位

### 多文档标签页

- 浏览器式多文档标签页：打开去重、相邻激活、溢出收缩与横向滚动
- **标签拖拽重排完全复刻浏览器手感**：拖拽签实时跟随鼠标，其余标签挤压让位动画，视口边缘自动滚动

### 界面

- **无边框窗口**：自绘标题栏（拖拽移动 / 双击最大化 / Aero Snap 吸附）、Windows 11 圆角、六向边缘缩放
- 「输出模式」与「粗糙布局」合并为单一配置项，思维负担减半

### 翻译管理

- **源文件指纹复用检测**：同一论文重复提交不再重复消耗 API 与等待时间
- 历史记录支持多选批量删除与右键单条删除，删除前自动释放文件句柄（Windows 文件锁）

---

## 🚀 性能

- **大文档加载优化**：280~380 页论文秒级打开、全程可交互（修复数百页文档加载即假死退出的问题）
  - 缩略图分批异步生成，占位图先行，不再阻塞主线程
  - 文本提取结果去抖合并，坐标更新限定可见窗口附近
- 翻译通道 HTTP 连接复用（keep-alive）与 Bing 令牌缓存，长文翻译网络开销显著下降
- 覆盖层渲染优化：页级版本缓存 + LRU 淘汰 + 单页像素上限，流式翻译期间不再卡顿

---

## 🛠 修复与优化

- 修复布局切换/全屏时 minimap 残留引用导致的崩溃
- 修复 QPdfDocument 句柄占用导致的历史记录文件无法删除问题
- 会话缓存 LRU 上限，长时间使用内存不再无界增长
- 跨栏合并文本块的列流切分与碰撞比例守卫，译文覆盖更贴合原版排版
- 调试 print 全部清理为 logger；界面字体改为运行时探测回退链

---

## 🧪 工程

- 新增 **pytest 测试套件（47 项）**：调度器 / 段构建过滤 / 碰撞渲染 / 持久化 / 标签拖拽 / 大文档性能
- 翻译调度核心抽离为无 Qt 依赖的独立模块，UI 层仅做信号桥接
- 打包链路增强：Nuitka onefile 单文件模式（启动缓存）、环境自检与编译器探测、全局异常钩子 + 文件日志（崩溃不再静默无痕）

## 📥 升级建议

> 本次核心是新增的「粗糙翻译」——适合**快速通读**：几秒钟出全文中文，配合双栏对照精读；需要出版级排版输出时再用 BabelDOC 精确翻译。两者共用侧边栏的语言与服务配置。
>
> 推荐下载 Nuitka 打包版本。实测 280~380 页论文加载全程可交互（事件循环最长阻塞 31ms）；粗糙翻译对免费/本地模型（Ollama）同样友好。
>
> 升级无需迁移配置，旧设置自动保留；此前因句柄占用删不掉的历史文件现在可以正常删除了。
